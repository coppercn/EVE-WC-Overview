# 凛冬联盟总览

本总览是基于[Z-S总览](https://imperium.news/z-s-overview-pack/)、[E-Uni总览](https://wiki.eveuniversity.org/Installing_the_EVE_University_Overview)
和[WinterCo.总览](https://forums.winterco.org/t/topic/3071)改进而成，根据自己的使用体验进行了特殊调整。

## 使用顺序：

加入游戏内频道`凛冬联盟总览`按照MOTD的指示或者按照本说明进行使用。

在开始之前先将所有总览文件放到正确的地址：`%UserProfile%\Documents\EVE`（Windows菜单直接粘贴就可以）下的`Overview`文件夹，如果没有就新建一个同名文件夹。

1. 点击总览右上角的三个点，选择`Open Overview Settings`。

   <img width="249" height="216" alt="image" src="https://github.com/user-attachments/assets/47efb69e-0012-48ee-bf25-5f2a97969cc5" />

2. 点击`Misc`栏，随后点击`Reset All Settings`，重置现有的总览。

   <img width="505" height="421" alt="image" src="https://github.com/user-attachments/assets/aaaa99c9-a5a2-403f-9340-cdcb279f1de0" />

3. 随后点击`Import Settings`，依次点击加载凛冬总览核心包以及五个预设包。**_每一次加载都必须勾选`Check All`！_**

   <img width="550" height="351" alt="image" src="https://github.com/user-attachments/assets/9196adcd-1343-46d6-83ea-6c19c84de78a" />

4. 选择一个你喜欢的框架加载，并且加载一个适合的`D-Scan`预设。

   <img width="237" height="174" alt="image" src="https://github.com/user-attachments/assets/78ea2463-153f-41a5-8f70-76117e4039b4" />

5. 完成以后建议重新登陆一下角色以保证总览正确刷新。

## 使用说明（参考[WinterCo.总览](https://forums.winterco.org/t/topic/3071)）

当你安装完成后，你的总览应该有七栏，分别是航行、作战、目标、生产、友军、跑蛋以及特殊。这七栏已经能够满足你的大部分日常需求。平时刷怪、散打、跑路用默认的这七栏一般就够了。但是总览里当然不仅仅只有这些，打开总览设置，在`Tabs`里面的`Filter`可以找到对应分类的更多预设。除此之外在`Bracket Filter`还可以选择不同的图标预设（平常你能在太空中看见的图标）。

航行：第一栏的航行其实就是为了方便你平时赶路用，用战斗栏也没问题。

作战：显示NPC、敌对以及一些建筑、太阳等必要内容，是通PVE、PVP通用总览，你可以在作战栏的`Filter`选择`作战：只有舰船`预设，那么你的作战总览上只会显示敌对的舰船，其他任何建筑物等都不会显示。

目标：目标栏默认显示无人机，你也可以把该栏的预设根据情况改为各种特定船型，例如隐轰。

生产：在这一栏你可以更改各类生产预设，默认的是挖矿预设。如果你需要刷怪或者打捞可以自行切换。

友军：如果你在跟队，并且你是后勤，你可以选择使用`友军：舰队`预设。这样你只能看到舰队成员，方便遥修。当然默认的预设也可以使用。

跑蛋：供你跃迁或者朝向的目标，里面有所有的行星和月亮，方便保住你的蛋。

特殊：默认为显示反诱导，在战斗栏中反诱导是默认显示的，并且如果你将总览按Icon（图标）排序，它会一直出现在前几位当中。反诱导一栏是为了避免被抓过于紧张或者忽视反诱导的存在而准备的。你也可以将这一栏当作其他栏的补充。

另外，所有`-残骸`的图标预设是可以进行Ctrl框选的，方便大航刷怪。可以看到，默认的预设已经能满足90%的情况，剩下的预设是为了成员在舰队中担任某些特殊职责而准备的。并且EVE现在支持显示多个总览窗口，十分建议将重要目标的总览放在新窗口中显示。
